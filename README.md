# Vamp Shmot

Интернет-магазин одежды: каталог товаров с брендами, корзина, оформление заказов,
регистрация/вход пользователей и панель администратора (товары, бренды, слайдер
на главной, заказы, контакты, пользователи).

## Стек

- **Backend:** Node.js + Express, `node:sqlite` (встроенная в Node база данных —
  внешний движок БД не нужен), JWT-авторизация, bcrypt для паролей, multer для
  загрузки фото.
- **Frontend:** обычные HTML/CSS/JS без сборщиков — лежит в `public/`.

## Требования

- Node.js **22.5 или новее** (нужен для встроенного модуля `node:sqlite`).

## Установка и запуск

```bash
npm install
npm start
```

Сервер поднимется на `http://localhost:3000` (порт можно поменять через
переменную окружения `PORT`).

При первом запуске сервер сам создаст файл базы `database.db`, папку
`uploads/` для загружаемых фото и заполнит магазин демо-данными: несколько
брендов, товаров и слайдов на главной.

## Настройка (.env)

Скопируйте `.env.example` в `.env` и при необходимости поменяйте значения:

```bash
cp .env.example .env
```

- `JWT_SECRET` — секрет для подписи токенов авторизации. **Обязательно
  замените на свою случайную строку перед тем, как выкладывать сайт в
  продакшен** — значение по умолчанию небезопасно.
- `ADMIN_PASSWORD` — пароль администратора, который создаётся при первом
  запуске (используется только при самой первой инициализации базы).
- `PORT` — порт сервера.

## Вход в админ-панель

По умолчанию создаётся один администратор:

- **Логин:** `admin`
- **Пароль:** `admin123` (или значение `ADMIN_PASSWORD` из `.env`, если он был
  задан до первого запуска)

Войдите под этим пользователем — в шапке сайта появится кнопка «Админка».

## Структура проекта

```
server.js           — весь backend: API, база данных, авторизация
public/
  index.html         — разметка одностраничного приложения
  style.css          — стили
  script.js          — вся логика фронтенда (каталог, корзина, админка)
  img/               — статические изображения (логотип)
uploads/             — сюда сохраняются загруженные через админку фото (создаётся автоматически)
database.db          — файл базы SQLite (создаётся автоматически)
```

## Что уже реализовано

- Каталог товаров, страница товара с галереей фото и выбором размера
- Бренды и страницы отдельных брендов
- Корзина (хранится в localStorage браузера) и оформление заказа
- Регистрация/вход, JWT-токены
- Личная страница «Мои заказы» у пользователя
- Админ-панель: CRUD товаров и брендов, управление слайдером на главной,
  просмотр и смена статуса заказов, редактирование контактов, список
  пользователей
- Загрузка фото файлом (drag & drop) или по прямой ссылке

## Возможные дальнейшие доработки

- Поиск и фильтры в каталоге (по цене, размеру, бренду)
- Пагинация каталога при большом количестве товаров
- Восстановление пароля по email
- Уведомления по email/Telegram о новых заказах
